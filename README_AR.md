# NIDAL GOLD AI — النسخة التجريبية الأولى

بوت تيليجرام تعليمي لتحليل الذهب XAU/USD. لا ينفذ صفقات ولا يتصل بحساب تداول.

## الوظائف
- `/start` بدء البوت وعرض الأوامر
- `/gold` تقرير فني تعليمي
- `/candles` قراءة نموذج آخر شمعة مغلقة
- `/trend` اتجاه EMA20/EMA50 وRSI وMACD
- `/alerts` تشغيل/إيقاف التنبيهات الفنية

## المتطلبات
1. بوت تيليجرام أنشأته عبر `@BotFather`، مع الاحتفاظ بـ BOT_TOKEN سرياً.
2. مفتاح API من Twelve Data.
3. استضافة سحابية تدعم Docker وBackground Worker، مثل Render.

## التشغيل محلياً للاختبار
أنشئ بيئة افتراضية وثبّت المكتبات:

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
```

انسخ `.env.example` إلى `.env`، ثم عيّن القيم في متغيرات البيئة قبل التشغيل. لا ترفع ملف `.env` إلى GitHub.

```bash
python -m app.bot
```

## النشر على Render
1. ارفع محتويات هذا المجلد إلى مستودع GitHub خاص.
2. في Render اختر New > Blueprint واربط المستودع.
3. أضف `BOT_TOKEN` و`TWELVE_DATA_API_KEY` كـ Secret Environment Variables.
4. أنشئ Background Worker من إعداد `render.yaml`.
5. افتح البوت في تيليجرام وأرسل `/start` ثم `/gold`.

قد تتغير أسعار وخطط الاستضافة أو حدود API؛ تحقق منها قبل النشر.

## ملاحظات مهمة
- يعتمد جلب البيانات على توفر رمز `XAU/USD` ضمن خطة Twelve Data وحسابك. إذا لم يكن الرمز متاحاً، راجع الرموز المدعومة في حساب مزود البيانات وعدّل `GOLD_SYMBOL`.
- يتم استبعاد أحدث شمعة عادةً لأنها قد تكون غير مكتملة، ويحلل البوت آخر شمعة مغلقة متاحة.
- التنبيهات والاشتراكات محفوظة في الذاكرة فقط في هذه النسخة، لذلك قد تُمسح عند إعادة تشغيل الخدمة.
- لا يوجد نموذج تنبؤ مضمون. المؤشرات الفنية تقديرية وقد تعطي إشارات خاطئة.
- لا تضف مفاتيح API أو كلمات مرور أو بيانات حساب تداول إلى المحادثات أو مستودع GitHub.
- هذه النسخة لا تفتح أو تغلق صفقات ولا تقدم توصيات استثمارية شخصية.
